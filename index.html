📝 Quản lý Hóa đơn đầu vào

Nhập từ ZIP/XML hoặc gõ tay, xem chi tiết hàng hóa, xuất Excel có kẻ khung đúng chuẩn.

💡 Có sẵn file .zip đã tải từ trang GDT (nút "Xuất xml")? Bấm "📦 Nhập từ file ZIP/XML hóa đơn" và chọn NHIỀU file cùng lúc (Ctrl/Shift + click trong hộp thoại chọn file), hoặc bấm "📁 Nhập cả thư mục (ZIP/XML)" để chọn LUÔN cả thư mục chứa (kể cả có thư mục con bên trong, ví dụ thư mục theo ngày) — không cần bấm chọn từng file — công cụ tự đọc đủ các trường, tự nhận biết "Hóa đơn điện tử" hay "Máy tính tiền", kể cả "Địa chỉ đơn vị mua hàng" mà cách gõ tay/dò trang không có. ✅ Dữ liệu tự động lưu lại trên trình duyệt của máy này (kể cả bản xem/in gốc, nút "🖨 PDF") — đóng tab/tắt trình duyệt, thậm chí xoá hẳn file .zip/.xml gốc đã nhập đều KHÔNG mất, vì dữ liệu đã được đọc và lưu vào trình duyệt ngay lúc nhập rồi, không phụ thuộc file gốc nữa. Chỉ mất khi tự bấm "🗑 Xóa hết" hoặc gỡ cài đặt tiện ích. 🔁 Hóa đơn trùng (cùng MST + Ký hiệu + Số hóa đơn) tự bỏ qua, không nhập/đọc lại.
